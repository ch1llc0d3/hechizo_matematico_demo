The Spells 🔮

Four Python demos that turn matchmaking, images, and popularity into math you can watch.

💘

Spell 1 — The Love Compass

hechizo_matematico.py

Turns two profiles into arrows in 3D space and measures the angle between them with cosine similarity. Smaller angle = more “hmm… interesting…” A mathematical crush detector.

👁️

Spell 2 — The Digital Eye

sociological_profiler.py

YOLO object detection on your webcam or a photo, plus EXIF metadata reading — when, where, which camera. A gossiping crystal ball for images. Educational only.

📈

Spell 3 — The Popularity Game

elo_ranking_sim.py

A pretend dating app run like an SRE system: 50 nodes with Elo scores, matches are successful transactions, dislikes are timeouts, and a load balancer keeps super-nodes in check.

🛡️

Bonus Spell — The HA Love Cluster

dating_sre_simulation.py

The Popularity Game’s sibling: exponential network effects when high-Elo nodes meet low-Elo nodes, traffic-aware load balancing, and a live Tier 1 “Desirability Peak” promotion log.

How the spell works: each profile becomes a vector in a 3-dimensional latent space (tech, café, asunción — the same feature map as the Python spell). The engine computes sim = A·B / (|A|·|B|), the angle θ = acos(sim), and the Probabilidad de Amarre as sim^1.3 × 100. Above 80% the vectors are already staring at each other in latent space… 👀

Cast the terminal spells 🧙‍♀️

Set up once, then run any spell from the command line. Full instructions live in the README.

python3 -m venv .venv
source .venv/bin/activate          # macOS/Linux (Windows: .venv\Scripts\activate)
pip install -r requirements.txt

python hechizo_matematico.py       # 💘 Spell 1 — Love Compass
python sociological_profiler.py --webcam   # 👁️ Spell 2 — Digital Eye
python elo_ranking_sim.py          # 📈 Spell 3 — Popularity Game
python dating_sre_simulation.py    # 🛡️ Bonus — HA Love Cluster
